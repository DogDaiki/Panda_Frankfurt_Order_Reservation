# 学祭向けリアルタイム注文予約システム

大学の学祭屋台向けに構築した、完全無料で運用可能なリアルタイム注文予約・混雑制御管理システムです。  
顧客用の予約画面と、パスワード不要で直感的に操作できる管理画面の2つで構成されています。

## 主な機能

### 1. 顧客用画面 (`index.html`)
- **動的リードタイム計算**: フランクフルトの注文数に応じた目安準備時間を計算し、選択可能な受取時間を制御。
- **キャパシティ＆二重予約防止**: 時間枠ごとの予約上限数および、1人あたりの同時保有予約数（最大2件など）を制御。
- **キャンセル申請**: 顧客側からのキャンセル申請（`user_cancelled`）とリアルタイムな状態表示。

### 2. 管理画面 (`admin.html`)
- **リアルタイム設定変更**: リードタイム、時間枠上限数、受取超過判定時間などのパラメータを即座に保存・全体反映。
- **キャンセル確認フロー**: 顧客側からのキャンセル申請を赤色カードで強調表示し、管理者の確認消去によって正しくキャンセルログへ分類。
- **売上・ログ分析**: 提供済み（`completed`）の注文のみを厳格に集計し、時間帯別売上グラフや商品別累計販売数を表示。

## テックスタック (Tech Stack)

- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+), Vite
- **Database**: Firebase Firestore (Realtime Sync / NoSQL)
- **Deployment**: Vercel / GitHub Pages
